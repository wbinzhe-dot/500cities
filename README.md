# 500cities: Code and Data
Replication material for "Beyond Proximity: How Racial and Income Differences Are Reflected in Mobility Patterns Across Neighborhoods in American Cities"

# Code
Available at code.zip 

# Data availability
## CBG-level visitation
Advan Research (https://advanresearch.com/) made this data available via the Dewey Data platform (https://www.deweydata.io/). The same dataset was previously circulated as SafeGraph’s Patterns. 

The original data underlying this article were provided by Dewey under an institutional license. The data are shareable upon request for replication purposes.
